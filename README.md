# Loyalty Social Website

A Next.js full-stack website for Loyalty Social, a new social lounge in Randallstown, Maryland.

## Features

- Dynamic 16:9 hero section with rotating tagline
- Business information and lounge overview
- Contact and reservations form
- Backend API route for contact submissions

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the site at `http://localhost:3000`
